# 🏰 gameEngine — 2D 塔防（目标：2v2 局域网联机）

用 **C++ + SDL3** 写的 2D 塔防游戏引擎，规划为 **2v2 局域网联机** 对战塔防：每个人既要**放塔守家**，也要**跳到对面地盘放怪进攻**。

## ✨ 已完成模块

- 🗺️ **地图 Map**：JSON 读图（格子类型 + 路径 `pathPoints`），防御检查、渲染上色
- 🏗️ **塔 Tower**：多态设计（箭 / 炮 / 魔法 / 冰 / 焦油塔），含持续伤害、减速、升级、冷却
- 👾 **怪 Monster**：沿路径平滑移动（勾股定理 + 归一化方向）、6 种类型（普通/坦克/快速/分裂/炸弹/毒）、状态效果（持续伤害 / 减速）
- 🎨 **SDL3 渲染**：格子地图 + 中文支持基础

## 🎮 规划玩法（2v2 联机）

- **2v2 两队各 2 人**，各有独立资金 / 基地 / 血量
- **手动放怪**进攻对面（非自动波次），多出怪点
- 放塔守家 + **经济塔**产钱，杀怪得钱
- 基地血量归零 → 失去操作权限（出局）
- 后期：**局域网联机**（socket）

## 🛠️ 技术栈

- **C++17**
- **SDL3**
- **nlohmann/json**（地图数据）

## 🚀 编译运行

```bash
g++ -std=c++17 main.cpp Map.cpp Tower.cpp Monster.cpp \
    -I "SDL3-3.4.14/x86_64-w64-mingw32/include" \
    -L "SDL3-3.4.14/x86_64-w64-mingw32/lib" \
    -lSDL3 -o game.exe
```

## 📁 目录结构

```
gameEngine/
├── main.cpp          # 主流程（SDL3 窗口 + 游戏循环）
├── Map.cpp/.h        # 地图：JSON 读图 + 路径
├── Tower.cpp/.h      # 塔：多态（箭/炮/魔法/冰/焦油）
├── Monster.cpp/.h    # 怪：沿路径移动 + 状态效果
├── filepath.json     # 地图数据
└── json.hpp          # nlohmann/json 单头文件
```
