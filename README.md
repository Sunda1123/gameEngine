## 🎮 项目是啥

用 **C++17 + SDL3** 写的 2D 塔防游戏引擎，规划为 **2v2 局域网联机**：每人既要**放塔守家**，也要**跳到对面地盘放怪进攻**。

## ✨ 已完成的（08-30 更新）

- 🗺️ **地图 Map**：JSON 读图（格子类型 + 路径）、防御检查、渲染上色
- 🏗️ **塔 Tower**：多态行为（攻击塔打怪 / **经济塔产钱**）、持续伤害、减速、升级、冷却
- 👾 **怪 Monster**：沿路径平滑移动（勾股定理 + 归一化）、6 种类型、状态效果
- 💰 **金币经济**：放塔/放怪扣钱、经济塔产钱、金币数字 HUD 显示
- 🩸 **基地血条**：基地血归 Player 管（封装），血条按血量绿/黄/红变色
- 🎨 **分层架构**：`engine/`（通用层：按钮/画字/血条）+ `game/`（塔防内容）+ SDL3 渲染 + GDI 中文

## 🛠️ 技术栈

- **C++17** · **SDL3** · **nlohmann/json**

## 🚀 编译运行

```bash
# 在 project_root/ 下
build.bat        # 一键编译，生成 game.exe
game.exe         # 运行
```

## 📁 目录结构（简化）

```
gameEngine/
├── engine/UI/        # 通用引擎层：Button / TextRenderer(画字) / HealthBar(血条)
├── game/
│   ├── UI/           # gameUI 主循环 + HUD（金币框）
│   ├── gameplay/     # Map / Tower / Monster / Player
│   └── data/         # 地图数据 filepath.json
└── project_root/     # build.bat + game.exe
```
